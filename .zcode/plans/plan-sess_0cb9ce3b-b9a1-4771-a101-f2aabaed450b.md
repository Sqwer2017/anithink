# План: полноценный плеер комнаты (звук для себя, мини-окно, «кино» с чатом справа)

## Подход (по твоим ответам)
- **Оставляем наш `<video>`+HLS** (стабильный синхрон) и поверх навешиваем **стеклянный фирменный chrome** — без переезда на ArtPlayer.
- **Полный экран с чатом справа** = отдельный **кино-режим (overlay)**: видео занимает почти всю ширину страницы, справа остаётся та же панель чата/участников.

## Файл
Только `src/app/watch/[id]/watch-party.tsx` (внутри он же содержит плеер/панель). Никакие другие файлы не меняю — синхрон и аути-логика уже работают.

## Что добавлю/поменяю

### 1. `ControlledVideo` → самодостаточный стеклянный chrome (поверх нашего video)
- Тот же HLS `<video>`, тот же imperativный handle (`getState/seek/togglePlay/setPlaying`) — синхрон как раньше.
- Внутри на оверлеях:
  - **Большой переключатель play/pause по центру** (показан при паузе / контакте).
  - **Нижняя панель** (как у ArtPlayer/стокового):
    - ползунок перемотки + текущее/общее время;
    - звук для себя: `volume` и `mute`, **не** транслируется в канал (только локально);
    - мини-окно — кнопка **PiP** (`video.requestPictureInPicture()`, «плавающее окно»);
    - кнопка **Полный экран** браузera (native).
- Управление перемоткой/pause идёт через родителя (авторизация + broadcast), а **громкость/мут/PiP/fullscreen — чисто локальные**.
- Данные для треканья позиции host сверху через тот же ref/onState — heartbeat и события не ломаем.

### 2. Вспомогательная кнопка задач режима доступности
- Если нельзя управлять (гость, не free) — поверх плеера мягкая полупрозрачная плашка «Управление у создателя», ввод в автослед.

### 3. Кино-режим (overlay) с чатом справа
- Кнопка «Развернуть на весь экран» над плеером → `fixed inset-0 z-40` тёмный overlay:
  - слева `flex-1` — тот же плеер (видео на весь доступный размер);
  - справа фиксированный столбец ~360-380px — панель чата+участников (тот самый aside, вынесу в общий рендер), на правом краю как ты и просил.
- Выход: крестик сверху + клавиша `Esc`.
- На мобильных чат под видео (как обычно), но в кино — компактно поверх.
- Рефактор: панель участников+чата вынесу в маленький вспомогательный `RoomSide` (пропсы: участники/чат/handlers), чтобы **не дублировать разметку** в обычном и кино-режиме.

### 4. Сборка и проверка
- `npm run build` (types).
- Smoke dev: `/watch/[id]?room=…` рендерится 200; переключение play/pause/seek — синхрон; volume/mute локально; PiP работает в Chromium; кино-режим показывает чат справа и закрывается по Esc.
